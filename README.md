# Stachis-PvP-Pack
> Stachi's PvP Pack

## Compatibility
Minecraft Version 1.20.4

## Download and Installation
> 1. Download the latest ressource pack from [here](.builds/Stachi's PvP Pack 1.9.2.zip)
```
Do not unzip the archive!
```
> 2. Open Minecraft > Options > Ressourcepacks > Open Ressource Pack Folder
> 3. Copy/Move the .zip-File in the folder and close it
> 4. Now activate it in the minecraft screen
> Done!
